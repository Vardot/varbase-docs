# Setting up Confirmations Message Settings Types

This section will explain how to set up confirmation settings types.

Please follow these instructions:

1. Go to **Manage \ Structure \&#x20;**_**Webforms.**_
2. Go to **Settings** on the desired webform.

<figure><img src="../../.gitbook/assets/image (35).png" alt=""><figcaption><p>Navigate the Settings</p></figcaption></figure>

3. Click on the **Confirmation** tab.
4. You will find “Confirmation types”, select which one you need to do the following actions but we recommend using: Page, Message, URL, or URL with message.

<figure><img src="../../.gitbook/assets/image (36).png" alt=""><figcaption><p>Confirmation Page</p></figcaption></figure>

5. Click on **Save**.

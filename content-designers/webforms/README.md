# Webforms

The **Forms** management page lists all available webforms, which can be filtered by the following: title, description, elements, category and status.

### View All the Webforms

To manage the Menus follow these steps:

1. Navigate to **Manage \ Structure \&#x20;**_**Webforms**_**.**
2. A separate page will load with all the forms.

**Webforms** can be managed by visiting the following link logged in with an administrator-level user \[_www.domain.com_**/admin/structure/webform**]

# Lesson 20: From Client Needs to a Varbase Plan

Turn a client's needs into a Varbase plan: run discovery, map each requirement to out of the box, configuration or build, choose a starting point among the site templates, prepare and run a demo, estimate honestly with an AI-assisted delivery baseline, and plan launch, updates and support.

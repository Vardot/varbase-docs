# Preview Content

Varbase allows you to preview how content will appear to site visitors before saving or publishing it. This helps ensure that formatting, media, and layout are correct before the content goes live.

## Using the Preview Button

1. While creating or editing content, click the **Preview** button located near the Save button on the content form.
2. The preview opens in a new view showing how the content will look on the front end of the site.
3. Review the content for accuracy, formatting, and visual presentation.
4. Click **Back to content editing** to return to the edit form and make any necessary adjustments.

## Responsive Preview

Varbase includes the **Responsive Preview** feature, which allows you to test how your content and site pages appear on different screen sizes and devices.

### How to Use Responsive Preview

1. Click the **Responsive Preview** icon in the admin toolbar. It is typically represented by a device icon.
2. A toolbar of device options will appear, showing a list of pre-configured devices.
3. Select a device to preview the current page at that device's screen dimensions.

### Pre-Configured Devices

Responsive Preview comes with several pre-configured device profiles, including:

- **iPhone 15** -- Mobile phone (portrait and landscape).
- **Galaxy S23** -- Mobile phone (portrait and landscape).
- **iPad Pro** -- Tablet (portrait and landscape).
- **Desktop** -- Standard desktop resolution.

These devices give you a representative view of how your content will look across common screen sizes.

### Closing Responsive Preview

Click the **Responsive Preview** icon again or click the close button to exit the preview mode and return to the normal view.

## Tips for Previewing Content

- Always preview content before publishing, especially for content with complex layouts, embedded media, or custom formatting.
- Check the content on multiple device sizes using Responsive Preview to ensure a good experience for all visitors.
- If the preview does not match your expectations, return to the edit form to adjust the content, layout, or media settings.
- Remember that preview shows the content as it will appear to visitors. Some admin-only elements will not be visible in preview mode.

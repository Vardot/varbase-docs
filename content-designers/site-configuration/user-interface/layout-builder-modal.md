# Layout Builder Modal

The **Layout Builder Modal** in **Varbase** provides an improved user experience for managing content layouts using the **Drupal Layout Builder**. It allows users to configure sections and blocks within a modal window instead of a full-page reload.

**Key Features:**

* **Improved UX**: Opens block and section configuration in a modal instead of a full-page reload.
* **Faster Editing**: Reduces page refreshes, making layout updates more efficient.
* **Seamless Integration**: Works with the **Varbase Layout Builder** and **Gin Admin Theme** for a modern UI.
* **Customizable Permissions**: Control access via Drupal’s permissions system.

### How to Navigate the **Layout Builder Modal** Page

1. Form **Configuration/ User interface/&#x20;**_**Layout Builder Modal.**_
2. You'll be redirected to the **Layout Builder Modal** page.
3. Update the information you want and click on Save Configuration button.

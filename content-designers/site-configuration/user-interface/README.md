# User Interface

The **User interface** area covers the tools that make the administration screens quicker to use. This page lists them.

- [Coffee](coffee.md): open any administration page by typing its name.
- [Navigation Settings](navigation-settings.md): the logo of the **Navigation** sidebar.
- [Responsive Preview](responsive-preview.md): how to check pages at phone, tablet and desktop sizes.

The settings live at **Configuration** \ **User interface** (`/admin/config/user-interface`) and need the **Super Admin** role. The cookie consent settings are there too. See [Cookie Consent](../../cookie-consent.md).

# Responsive Preview

Visitors use phones, tablets and large screens, so check how a page looks at each size before you publish. The **Responsive Preview** module is not included in Varbase 11; this page shows the ways to check screen sizes instead.

## Drupal Canvas Pages

In the Drupal Canvas editor, choose **Mobile**, **Tablet**, **Desktop** or **Large Desktop** under the page, or click **Preview** to see the page without the editing panels. See [Preview and Publish](../../building-pages-with-drupal-canvas/preview-and-publish.md).

## Blog Posts and Other Content

- For a **Utility page**, click **Preview** on the form. See [Preview Content](../../content-management/preview-content.md).
- For a published item, open it on a phone, or make your browser window narrow.
- Most browsers also have a device mode in their developer tools that shows a page at phone and tablet sizes.

## What to Check

- Text is readable without zooming.
- Images are not cut off in a bad place; if they are, set the focal point. See [Image](../../media-management/uploading-media-files/image.md).
- Columns stack in a sensible order on a phone.
- Buttons and links are big enough to tap.
- Menus open and close.

{% hint style="info" %}
A developer can add the **Responsive Preview** module if your team wants a device previewer on the site itself.
{% endhint %}

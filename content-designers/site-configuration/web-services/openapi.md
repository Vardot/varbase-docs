# OpenAPI

OpenAPI documentation describes the site's API in a standard format, so developers can see which content they can read and how. It is a developer tool; this page tells editors where it is and who uses it.

## Where It Is

**Configuration** \ **Web services** \ _**OpenAPI**_ (`/admin/config/services/openapi`) lists the API documentation for **JSON:API** and the REST resources, which developers can open in an interactive viewer.

Opening it needs the **Super Admin** role, or a permission your development team grants.

## Who Uses It

- Developers building a mobile app or another site that shows your content.
- Integration partners connecting your site with other systems.

If someone outside your team asks how to get content from your site, point them to your development team, who can share the documentation and the access they need.

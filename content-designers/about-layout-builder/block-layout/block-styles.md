# Block Styles

Users can control the block style, background, borders, alignment, etc easily with Drupal while **adding** or **editing** the block as the following:

### Background:

Users may add the block background as:

1. Color.
2. Image.
3. Video

<figure><img src="../../../.gitbook/assets/image (17) (1).png" alt="" width="514"><figcaption><p>Block Background Style</p></figcaption></figure>

### Typography:

Users can control the text color and alignment in the block.

<figure><img src="../../../.gitbook/assets/image (18) (1).png" alt="" width="513"><figcaption><p>Block Typography Style</p></figcaption></figure>

### Spacing:

Users can control the block padding (inner space of the block) and margin (whitespace available surrounding the block)

<figure><img src="../../../.gitbook/assets/image (19) (1).png" alt="" width="497"><figcaption><p>Block Spacing Style</p></figcaption></figure>

### Border:

Users can control the borders (full/specific edge) by choosing the border style, width, color, and radius.

<figure><img src="../../../.gitbook/assets/image (20).png" alt=""><figcaption><p>Block Border Style</p></figcaption></figure>

### Shadow:

Users can control the section shadow type and have the ability to preview the option they choose.

<figure><img src="../../../.gitbook/assets/image (21).png" alt=""><figcaption><p>Block Shadow Style</p></figcaption></figure>

### Animation:

Users can control the animation that the block will display.

<figure><img src="../../../.gitbook/assets/image (22).png" alt=""><figcaption><p>Block Animation Style</p></figcaption></figure>

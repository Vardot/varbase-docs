# Plan the Launch

Use this combined checklist from the sections of this guide in the weeks before launch. Each line has an owner and a date.

## The Checklist

A combined checklist from the sections of this guide:

- [ ] Site template chosen; optional recipes listed (AI, multilingual, sign-in, API)
- [ ] Content model and taxonomy workshop held; vocabularies have owners
- [ ] Component inventory against Vartheme BS5 done
- [ ] Role matrix and approval chain agreed, including who publishes Canvas pages; **Role assign** set up for the Site Admin
- [ ] Policy pages published; every menu link leads to a published page (on Varbase Starter, publish the **Privacy policy** page and create a **Terms and Conditions** page or disable its footer link)
- [ ] Canvas page addresses planned (no automatic alias); route into search engines planned (not in the sitemap)
- [ ] Redirects from the old site imported and tested; **Fix 404 pages** cleared
- [ ] Sitemap in the robots file, submitted to search engine accounts the client owns
- [ ] Languages and translation owners named; forms and emails translated
- [ ] Every form has a handler that tells someone, and a plan for where its data goes and how long it is kept
- [ ] Accessibility alerts cleared; accessibility target and audit planned
- [ ] Every role tested with real tasks; email delivery confirmed in every language
- [ ] Security headers reviewed; security test done; incident plan agreed
- [ ] Consent services matched to the outside services the site actually uses
- [ ] AI pilot scope, provider, budget and evaluation questions agreed; AI context and guardrails in place
- [ ] Hosting, email delivery, backups and monitoring in the proposal

Three screens help with the checks: the **SEO checklist** (`/admin/config/search/seo-checklist`), the **Content Accessibility** report (`/admin/reports/editoria11y`) and **Fix 404 pages** (`/admin/config/search/redirect/404`).

{% hint style="info" %}
The **SEO checklist** may say on every visit that it found unchecked items that were already completed and checked them for you. Nothing is recorded until someone clicks **Save**, so save the checklist once and the message stops.
{% endhint %}

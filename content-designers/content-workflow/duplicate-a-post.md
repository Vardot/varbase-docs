# Duplicate a Post

Sometimes the best start for a new post is an old one, such as this year's event announcement based on last year's. The **Duplicate** tab copies a blog post or utility page into a new item, with its fields filled in. The copy goes through the workflow like any new post, so nothing reaches visitors before it is reviewed.

## Steps

1. Open the post you want to copy, on the site or from the content list.
2. Click the **Duplicate** tab, or choose **Duplicate** in the item's **Operations** on the content list.
3. The create form opens with the fields of the original filled in, and a message naming the post you are duplicating.
4. Change the **Title** and everything else that should differ: dates, images, the description, the tags.
5. Set **Save as** and click **Save**. Until you save, nothing is created.

{% hint style="info" %}
The copy starts unpublished and has its own address, revisions and history. The original is not changed.
{% endhint %}

## Tips

- Write a revision log message such as "Copied from the 2026 open day post", so the history says where the copy came from.
- Check the **URL alias** and the SEO fields: a copied description that still talks about last year is easy to miss.
- For a series of Drupal Canvas pages, use **Duplicate page** in the editor instead. See [Launch a Series of Campaign Pages](../building-pages-with-drupal-canvas/templates-and-page-types/launch-a-series-of-campaign-pages.md).

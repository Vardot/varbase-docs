# Patterns

A pattern is a whole page section, already built and filled with starter content: a hero slider, a set of feature cards, a contact form with details, a call to action. Inserting a pattern is the quickest way to build a page that matches your site's design.

## Patterns That Come With Varbase

| Pattern | What it is |
| --- | --- |
| **Hero Slider** | Large slides with a heading, text and button. |
| **Page Intro Banner** | The header band of an inside page, with a title and a short introduction. |
| **Feature Cards** | Cards with an icon, a title and a short text. |
| **Feature Highlight** | One feature with an image and a description. |
| **Image Cards** | A row of cards, each with a picture or icon and a short text. |
| **Text with Cards** | An introduction next to a set of cards. |
| **Counters** | Key figures, such as numbers of users or projects. |
| **Call to Action Banner** | A banner with a message and a button. |
| **Call to Action Cards** | Two cards side by side, each pointing to a next step. |
| **FAQ Accordion** | Questions and answers that open and close. |
| **Latest Blog Posts** | The newest blog posts, updated automatically. |
| **Contact Form with Info** | A contact form beside contact details. |
| **Ask AI (cited answers)** | A box where visitors ask a question and get an answer that cites your site's content. |

**Site Header** and **Site Footer** add the standard header or footer as a section of a page. The header and footer shown on every page come from the page template. See [Page Templates](page-templates.md).

## Inserting a Pattern

1. Open the page in the editor.
2. Click **Library**, then the **Patterns** tab.
3. Drag the pattern onto the page, or right-click it and choose **Insert**.
4. Select the pieces inside it, such as headings, text, buttons and images, and change them on the **Settings** tab.

Each insert is an independent copy. Changing it on one page never changes the pattern or other pages.

## Saving Your Own Pattern

A **Content Admin** or **Site Admin** can save a section they built as a new pattern:

1. Right-click the component that holds the section, for example its **Section**.
2. Choose **Create pattern**.
3. Enter a name and save.

The new pattern appears on the **Patterns** tab for everyone who builds pages. To rename or delete it, right-click it in the **Library**.

## Tips

- Replace every piece of starter text and every starter image before publishing.
- Build a page from patterns first, then add single components for the details.
- Save a pattern for any section your team builds more than twice.

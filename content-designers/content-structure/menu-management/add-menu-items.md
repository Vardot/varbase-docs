# Add Menu Items

### **Adding Link to Menu**

In order to add a new link to one of the menus, follow these steps:&#x20;

1. Click **Manage\Structure\\**_**Menus**_.

<figure><img src="../../../.gitbook/assets/image (236).png" alt=""><figcaption><p>Menus</p></figcaption></figure>

2. Select the menu you want to add to. For example, **Main navigation.**
3. Click **Edit menu.**

<figure><img src="../../../.gitbook/assets/image (235).png" alt=""><figcaption><p>Edit Menu</p></figcaption></figure>

4. Click on **Add link** button.

<figure><img src="../../../.gitbook/assets/image (237).png" alt=""><figcaption><p>Add a Link to the Menu</p></figcaption></figure>

5. A separate page will load with fields. Users should insert the menu link title (the title you want to appear to the user) and the path (the url you want the link to send to).

<figure><img src="../../../.gitbook/assets/image (238).png" alt=""><figcaption><p>Add Menu Title and Link</p></figcaption></figure>

6. Click **Save** to add this item to the menu.
7. After Saving, navigate back to the menu to check the order of the item&#x73;**.**

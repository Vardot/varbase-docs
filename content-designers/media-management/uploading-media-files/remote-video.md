# Remote Video

Remote video is easy to be added in Drupal. As mentioned before you can remote video from:

1. Media page
2. WYSIWYG
3. Remote video field

{% hint style="info" %}
While it is not required, it is highly recommended to load a cover image along with your remote video. This will speed up the load time of your site and increase your SEO ranking.
{% endhint %}

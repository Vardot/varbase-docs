# Uploading Media Files

## Media in Drupal:

Drupal Media fields are different, you can easily add images, Gallery, video, files, and other several types.\
\
&#x20;You can add **Media** from several places in your website: &#x20;

### 1. Media node page

1. Select **Media** from the **Manage** administrative men&#x75;**.**
2. Select **Add media**_._
3. Select type of the Media that you need to add.

<figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption><p>Add New Media as a Node Item</p></figcaption></figure>

### 2. Media field

You can add **Media** from the Manage administrative menu.

<figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption><p>Add media from the Manage Administrative Menu</p></figcaption></figure>

### 3. WYSIWYG

Any time you can add media in the WYSIWYG in Rich text editor.

<figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption><p>Add Media in the WYSIWYG</p></figcaption></figure>

### 4.  Blocks

You can upload media directly from the blocks that require adding media in the layout builder:

1. Open the layout builder.
2. **Add** a block that requires media <mark style="background-color:red;">\[ex: Media (image/video)].</mark>
3. Click on **Add Media** button.
4. Click on **Select files** button.
5. Select the media from your device.
6. **Save** the media in the media library.
7. **Save** the block.

<figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption><p>Adding Block from the Media Library</p></figcaption></figure>

<figure><img src="../../../.gitbook/assets/image (42).png" alt=""><figcaption><p>Add Media Window</p></figcaption></figure>

{% hint style="info" %}
**Note:** You can edit or delete any _Media_ file from the Media library page.&#x20;
{% endhint %}

# Delete a Media Item Safely

Removing an image from a page does not delete it from the library. Delete an item only when nothing uses it any more, because a deleted image leaves a gap on every page that showed it.

## Steps

1. On the **Media** page, find the item and open it.
2. Check its **Usage** tab (for example `/media/2/edit/usage`). Images placed on Drupal Canvas pages are not listed there yet, so an item used only on Canvas pages shows "There are no recorded usages". Check those pages too.
3. Replace the item on any page that still uses it.
4. Choose **Delete** in the item's operations and confirm. The item moves to the **Trash**.

If you deleted the wrong item, restore it from the **Trash**, on the **Media entities** tab. See [Trash](../content-workflow/trash.md).

## Who Can Delete

Editing and deleting depend on the role and the media type: for example, an **SEO Admin** can edit any image but not documents. On a new site, a **Content editor** can delete any media item, such as an image, a video or a document.

## Planning Notes

- Decide who may delete media. Some clients keep it for senior roles.
- Plan a library clean-up once or twice a year: oldest items, usage, names and descriptions.

# Varbase AI Agents

The **Varbase AI Agents** recipe adds an AI chatbot for site administration, with several agents that each handle one kind of task. It builds on **AI Agents**, **AI Assistant API** and **AI Chatbot**.

## Recipe Type

Varbase AI

## Drupal.org Project

[https://www.drupal.org/project/varbase\_ai\_agents](https://www.drupal.org/project/varbase_ai_agents)

## Before You Apply

Apply [**Varbase AI Base**](varbase-ai-base.md) first.

## Installation

```bash
ddev composer require drupal/varbase_ai_agents:~1.0.0
ddev drush recipe ../recipes/varbase_ai_agents
```

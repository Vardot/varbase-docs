# Varbase Modules

## Overview

**Varbase 9.2.x** and **Varbase 10.1.x** are built from Varbase modules. Each module is a Drupal.org project that ships one feature with its configuration, and the Varbase installation profile requires the core set for its line. The rest are optional add-ons. **Varbase 11.0.x** installs features with [Varbase Recipes](../varbase-recipes/README.md) instead, and keeps the few modules that its recipes and theme need.

Each module has its own version line per Varbase line. The tables below show the latest release of each line, checked on 22 November 2026 against the Drupal.org release history of each project. A dash means the module has no line for that Varbase version.

## Adding a Module

On Varbase 9.2.x and 10.1.x, require the module line that matches your Varbase line, then enable it. For example, to add FAQs to a Varbase 10.1.x site:

```bash
ddev composer require drupal/varbase_faqs:~10.1.0
ddev drush en varbase_faqs
```

On Varbase 11.0.x, apply the recipe that brings the feature, such as [Varbase Auth Base](../varbase-recipes/varbase-auth-base.md) for **Varbase Auth**. The recipe requires the module and applies its configuration.

For the recipes and modules of Varbase 11.0.x with their version lines, see [Module and Recipe Inventory](../module-and-recipe-inventory.md).

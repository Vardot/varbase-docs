# Vartheme BS5 Horizon Aid

**Vartheme BS5 Horizon Aid** is the front-end theme of the **Horizon Aid** site template. It is a copy of [**Vartheme BS5**](../vartheme-bs5/README.md) with its own design system and the components that site template needs, and it is a starter kit too.

## Theme Type

Front-end theme and starter kit

## Drupal.org Project

[https://www.drupal.org/project/vartheme\_bs5\_horizonaid](https://www.drupal.org/project/vartheme_bs5_horizonaid)

## Used By

The [**Horizon Aid**](../../site-templates/horizon-aid.md) site template installs it as the default theme.

## What It Provides

Everything **Vartheme BS5** provides: the **Header**, **Content** and **Footer** regions, the single directory components, the **Bootstrap icons** pack, and the **Containers** and **Sticky header** settings at **Administration** \ **Appearance** (`/admin/appearance/settings/vartheme_bs5_horizonaid`). See [Vartheme BS5](../vartheme-bs5/README.md).

On top of those, it adds these components for **Horizon Aid**:

- **Hero Banner**
- **Country Card**, **Country Slider**, **Map** and **Map Info Card**
- **Programs** and **Program Tab**
- **Events Card**, **Profile Card**, **Icon Text Card** and **Impressed Card Slider**

## Building Your Own Theme

Generate a new theme from it instead of editing it:

```bash
php core/scripts/drupal generate-theme mytheme --starterkit vartheme_bs5_horizonaid
```

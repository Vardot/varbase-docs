# Varbase Themes

## Overview

Varbase 11.0.x ships its front-end themes as Bootstrap 5 starter kits built from single directory components. **Vartheme BS5** is the default theme, and each site template brings its own theme. A recipe or a site template requires each one, so Composer adds it for you.

## Available Themes

| Theme | Description |
| --- | --- |
| [Vartheme BS5](vartheme-bs5/README.md) | Bootstrap 5 front-end theme and starter kit. |
| [Vartheme BS5 Educare](vartheme-bs5-educare/README.md) | Front-end theme of the **Educare** site template. |
| [Vartheme BS5 Horizon Aid](vartheme-bs5-horizonaid/README.md) | Front-end theme of the **Horizon Aid** site template. |
| [Vartheme BS5 Rightup](vartheme-bs5-rightup/README.md) | Front-end theme of **The Rightup** site template. |

{% hint style="info" %}
To build your own theme, generate it from one of these starter kits rather than editing the theme itself. See [Creating Your Own Theme](../../theme-development-with-varbase/creating-your-own-theme.md).
{% endhint %}

# Vartheme BS5 Educare

**Vartheme BS5 Educare** is the front-end theme of the **Educare** site template. It is a copy of [**Vartheme BS5**](../vartheme-bs5/README.md) with its own design system and the components that site template needs, and it is a starter kit too.

## Theme Type

Front-end theme and starter kit

## Drupal.org Project

[https://www.drupal.org/project/vartheme\_bs5\_educare](https://www.drupal.org/project/vartheme_bs5_educare)

## Used By

The [**Educare**](../../site-templates/educare.md) site template installs it as the default theme.

## What It Provides

Everything **Vartheme BS5** provides: the **Header**, **Content** and **Footer** regions, the single directory components, the **Bootstrap icons** pack, and the **Containers** and **Sticky header** settings at **Administration** \ **Appearance** (`/admin/appearance/settings/vartheme_bs5_educare`). See [Vartheme BS5](../vartheme-bs5/README.md).

On top of those, it adds these components for **Educare**:

- **Program Card**, **Dated Vertical Card**, **Action Text Card** and **Quote Card**
- **Mega menu** for the main navigation
- **Subtitle**

## Building Your Own Theme

Generate a new theme from it instead of editing it:

```bash
php core/scripts/drupal generate-theme mytheme --starterkit vartheme_bs5_educare
```

# Add a New Term

This section will show you how to add items to the EntityQueues as example:

1. Go to **Structure**/_**EntityQueues**_ page.
2. Select the EntityQueue list that you want to add a term to (<mark style="background-color:red;">eg. Media Hero Slider</mark>).
3. Click on the drop-down menu _**Edit items**_**.**

<figure><img src="../../../.gitbook/assets/image (231).png" alt=""><figcaption><p>Entityqueues List</p></figcaption></figure>

4. Click on _**Add existing item**_**,** then choose your specific item to add it into this EntityQueue

<figure><img src="../../../.gitbook/assets/image (232).png" alt=""><figcaption><p>Add Existing Item to EntityQueues</p></figcaption></figure>

5. Select the node you want to add to the entityqueue.
6. Click on _**Add item**_ button.
7. Click on _**Save**_.

<figure><img src="../../../.gitbook/assets/image (233).png" alt=""><figcaption><p>Adding Item to the Entityqueue</p></figcaption></figure>

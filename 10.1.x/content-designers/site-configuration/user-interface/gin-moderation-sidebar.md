# Gin Moderation Sidebar

The **Gin Moderation Sidebar** in **Varbase** is a feature designed to enhance content moderation and workflow management within the **Gin Admin Theme**.&#x20;

* **Streamlined Moderation**: Provides an easy-to-access sidebar for managing content moderation states.
* **Workflow Integration**: Works with the **Workbench Moderation** or **Content Moderation** modules to allow smooth content approvals.
* **Quick Actions**: Editors and moderators can change moderation states (e.g., Draft, Published, Needs Review) without leaving the current page.
* **User-Friendly UI**: Part of the Gin Admin Theme, offering a modern and intuitive experience.
* **Customizable**: Can be adjusted based on user roles and permissions for better workflow control.

### How to Navigate the Gin Moderation Sidebar Page

1. Form **Configuration/ User interface/&#x20;**_**Gin Moderation Sidebar.**_
2. You'll be redirected to the **Gin Moderation Sidebar** page.
3. Update the information you want and click on Save Configuration button.

# Moderation Sidebar

The **Moderation Sidebar** in Varbase enhances content workflow by allowing users to change moderation states directly from a sidebar. It integrates with **Drupal’s Content Moderation** system for efficient editorial management.

**Key Features:**

* **Quick Content Moderation**: Easily switch between Draft, Needs Review, and Published states.
* **Workflow Integration**: Works with Drupal’s **Content Moderation** and **Workflows** modules.
* **User-Friendly UI**: Provides a seamless experience within the **Gin Admin Theme**.
* **Role-Based Access**: Permissions can be assigned to editors, reviewers, and publishers.

### How to Navigate the Moderation Sidebar Page

1. Form **Configuration/ User interface/&#x20;**_**Moderation Sideba**_&#x72;_**.**_
2. You'll be redirected to the **Moderation Sidebar** page.
3. Update the information you want and click on Save Configuration button.
